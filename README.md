# Cassandra-scripts
Cassandra scripts for day to day activities

1)rollOver script helps to do rollover restart of the cluster(restarting one node at a time)
2)repair scripts helps to run the repair -pr, repair -pr will be running all the nodes in the cluster(one node at a time)
3)describecluster, the script will be running describecluster on all the nodes, script will make sure that all the nodes are connecting from all the nodes in a cluster.
